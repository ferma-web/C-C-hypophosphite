Добавить по шифру реакции из OdanLab

Если реакция уже есть в OdanLab-проекте, не нужно рисовать структуру заново — введите её шифр (например AAP-36) и нажмите «Найти». Часть полей формы ниже заполнится автоматически (название, выход, реагенты). Структуру (SMILES/превью) и категорию нужно будет указать вручную — кэш не хранит картинки, чтобы не тянуть их для всех 149 реакций проекта заранее.

1. Нарисуйте структуру

Нарисуйте молекулу прямо здесь, затем нажмите «Перенести структуру в форму ↓» — SMILES подставится в поле ниже автоматически, копировать вручную не нужно.

Встроенный редактор на этой странице не найден (см. README.md, раздел «Встроенный Ketcher» — нужно один раз добавить его файлы в репозиторий). Пока этого не сделано, можно нарисовать структуру во внешнем редакторе и вставить SMILES вручную: откройте Ketcher (публичная демо-версия EPAM), нарисуйте молекулу, затем File → Save As → SMILES (или скопируйте SMILES из панели инструментов) и вставьте строку в поле ниже. Подойдёт любой инструмент, который умеет отдавать SMILES (Ketcher, MarvinJS, PubChem Sketcher и т.д.).
